## Resumo

Catálogo canônico das fichas de análise por lote do `analise-ppc`.

Cada arquivo JSON descreve uma verificação individual aplicada ao PPC completo, com pergunta, rubrica, evidência mínima, referências normativas e estados permitidos.

O campo `secoes_preferenciais` deve indicar áreas pretendidas do PPC, não números literais de seção. Use somente os valores aceitos pelo schema `schemas/ficha.schema.json`, como `identificacao_curso`, `perfil_egresso`, `organizacao_curricular` e `referencias_normativas`.
