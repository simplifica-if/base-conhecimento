## Resumo

Contratos mínimos de referência para formatos usados pelo `analise-ppc`.

Os arquivos deste diretório não compõem o runtime do parecer. Eles documentam o formato esperado de fichas, batches e respostas de lote.

Os contratos verificáveis ficam em `../schemas/` e são conferidos por `scripts/validar_base_analise.py`.
