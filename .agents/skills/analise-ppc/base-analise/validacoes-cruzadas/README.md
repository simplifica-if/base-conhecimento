## Resumo

Catálogo das validações cruzadas do `analise-ppc`.

Cada arquivo JSON descreve uma verificação transversal entre seções, achados ou elementos estruturais do PPC. Essas validações são avaliadas em etapa própria, por agente, após as fichas por lote.

O campo `secoes_relacionadas` deve indicar áreas pretendidas do PPC, não números literais de seção. Use o mesmo vocabulário validado pelas fichas, como `justificativa_objetivos`, `concepcao_metodologia`, `avaliacao_aprendizagem` e `infraestrutura`.
